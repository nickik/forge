# C8 — scalar ABI and calls

C8 is the first Forge FIR -> CLIF call milestone. It extends the verified scalar backend without defining aggregate ABI policy.

## Supported

- target-native scalar signatures for the current AArch64 and RV64 validation targets;
- direct calls to functions in the same FIR module;
- first-class function references;
- indirect calls through an exact Forge function type;
- scalar integer, bool, pointer, reference and function-pointer parameters;
- zero or one scalar return value;
- explicit rejection of required tail calls;
- explicit relocation boundary for direct calls and function addresses.

## Required invariants

Forge semantic types remain authoritative. CLIF representation equality is not enough: call arguments, function-reference signatures and call results must match the exact FIR types even when two Forge types share a CLIF representation.

The C7 block scheduler remains authoritative for cross-block scalar dependencies. C8 adds call arguments and indirect callees to scheduler dependencies so non-topological FIR block vector order cannot produce use-before-lowering failures.

Direct callees must exist in the current FIR module. Function references must exactly match the referenced function signature. Indirect calls must use a resolved `Ty::Function` signature.

C8 does not silently lower a required tail call as an ordinary call.

## Still out of scope

- aggregate layout and aggregate call decomposition;
- C ABI struct classification as Forge-native ABI policy;
- varargs;
- closures;
- global-address lowering;
- object emission/linking and relocation resolution;
- SIA physical register assignment.

Machine-code emission remains valid only for relocation-free functions. Direct calls and function addresses may produce relocations and therefore stop at the existing explicit machine-code relocation boundary.

## Validation

C8 must preserve every C7 test and additionally validate on AArch64 and RV64:

- direct scalar calls and relocation rejection;
- relocation-free indirect calls;
- first-class function references;
- required-tail-call rejection;
- non-topological call dependencies through the C7 scheduler;
- exact semantic type mismatch rejection where CLIF representations coincide;
- final CLIF verification and the full strict workspace CI gate.
